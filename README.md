## ✨ Sobre o projeto

A **GT Store – Achadinhos Tech** é um projeto de desenvolvimento web criado para reunir produtos tecnológicos, acessórios, gadgets e itens para setup em uma vitrine digital moderna e intuitiva.

A plataforma tem como propósito facilitar a descoberta de produtos e promoções, direcionando os visitantes para ofertas disponíveis em lojas online.

O projeto foi desenvolvido com foco em **design moderno, experiência do usuário (UX/UI), organização de produtos e navegação intuitiva**, utilizando uma identidade visual inspirada em interfaces tecnológicas premium.

## 🎨 Identidade visual

O projeto utiliza uma proposta visual **Dark Tech Premium**, com elementos inspirados em interfaces modernas e tecnológicas.

- 🌑 Fundo escuro com tons de preto e azul-marinho.
- 💎 Detalhes em azul elétrico e ciano.
- 🧊 Elementos visuais inspirados em Liquid Glass.
- ✨ Animações e efeitos de interação.
- 📐 Organização visual focada na experiência do usuário.
